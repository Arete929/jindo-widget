설치하는 법

코드 서명을 하지 않은 앱이라 Windows 가 한 번 물어봅니다. 아래 순서대로 누르면 됩니다.

  1. 위 단추를 누르고 「저장」(또는 「열기」)

    받은 HyewonDesk-Setup 파일을 두 번 눌러 실행합니다.

  2. 파란 「Windows의 PC 보호」 창에서 「추가 정보」

    「실행 안 함」 단추만 보여도 당황하지 마세요. 글자 추가 정보를 누르면 단추가 하나 더 생깁니다.

  3. 「실행」 을 누르면 설치 끝

    잠깐 뒤 혜원이지가 저절로 뜹니다. 바탕화면과 시작 메뉴에도 아이콘이 생깁니다.

한 번 설치하면 새 버전은 저절로 받아집니다. 다시 내려받으실 일이 없습니다.

처음 켰을 때

  1. 바탕화면에 작은 창이 뜹니다. 제목 줄을 잡아 옮기세요
  2. 톱니바퀴 ⚙️ 를 눌러 학교와 선생님 이름을 고릅니다
  3. 그러면 시간표·급식·주간업무가 저절로 채워집니다
  4. 출결을 쓰시려면 «출결» 탭에서 연결 코드(김진호에게 메신저로 받으세요)를 붙여 넣고, 나는 누구를 고릅니다. 학년부장·교무부장·교장·교감 선생님은 확인번호도 넣습니다

창을 닫아도 꺼지지 않고 작업표시줄 오른쪽 아래에 남아 있습니다. 제목 줄의 ⤢ 를 누르면 넓은 창으로 크게 볼 수 있습니다.

단축키

혜원이지 창을 누른 뒤 쓰세요. 글을 적는 칸에 있을 때는 글자로 들어가므로 먹지 않습니다.

1 ~ 8 그 번째 탭으로 곧장 — 넓은 창은 왼쪽 메뉴 위에서부터(대시보드가 1), 작은 창은 위쪽 탭 왼쪽부터 셉니다. 아래 «화면 둘러보기» 의 숫자가 넓은 창 기준입니다
Tab / Shift+Tab 다음 탭 / 앞 탭
` 전체화면 켜기·끄기 — 숫자 1 왼쪽, Esc 바로 아래의 물결(~) 키입니다. 한 번 더 누르면 원래 크기로
Esc 창 숨기기 — 꺼지지 않고 작업표시줄에 남습니다
⊞+1 어느 화면에서든 혜원이지 부르기 — 작업표시줄에 붙여 두면 됩니다(바로 아래 설명)

작업표시줄에 붙여 두고 ⊞+1 로 부르기

자주 쓰시면 이렇게 해 두세요. 어느 화면에 있든 키 두 개로 곧바로 올라옵니다.

  1. 시작 단추를 누르고 혜원이지를 찾습니다 (바탕화면 아이콘도 됩니다)
  2. 마우스 오른쪽 클릭 → 작업 표시줄에 고정
    안 보이면 「추가 옵션 표시」나 「자세히」 안에 있습니다
  3. 작업표시줄에 생긴 아이콘을 왼쪽 끝으로 끌어다 놓습니다
  4. 이제 ⊞+1 로 부릅니다
    ⊞ 는 스페이스바 왼쪽의 창문 모양 키입니다

몇 번째에 두었는지에 따라 숫자가 바뀝니다 — 두 번째면 ⊞+2, 세 번째면 ⊞+3. 시작·검색·위젯 단추는 세지 않고 앱 아이콘만 셉니다.

혜원이지는 창을 닫아도 꺼지지 않으므로, ⊞+1 을 누르면 새로 켜지는 것이 아니라 있던 창이 그대로 다시 올라옵니다.

표·들여쓰기까지 원문 그대로. 지난 주·다음 주도 넘겨 보고, 인쇄도 됩니다.

3 학사일정

3월부터 이듬해 2월까지 한 줄로 이어서 봅니다.

4 출결

학년 출결목록 시트를 앱에서. 담임은 적기·고치기·월별 인쇄, 학년부장은 수정요청, 관리자는 보기. «점검하기» 로 서류·출석부·NEIS 를 체크합니다.

5 급식

나이스에서 가져온 식단을 주 단위로 넘겨 봅니다.

6 컴시간

내 시간표와 학급 시간표. 이번 주 바뀐 수업(보강·교체)까지 반영됩니다.

7 학생기록

학급 → 학생 → 분류로 적어 두고, 나중에 통계로 모아 봅니다.

8 바로가기

자주 가는 곳을 담아 두고 한 번에. 나눠 드린 웹앱도 저절로 목록에 뜹니다.

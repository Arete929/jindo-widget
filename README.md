# 수업진도 위젯 (JindoWidget)

체육 수업진도 대시보드([jindo-dashboard.web.app](https://jindo-dashboard.web.app))의
오늘 수업·이번 주 시간표·반별 진도를 바탕화면에 항상 띄워두고 보는 Windows 위젯입니다.

수업 중간에 "다음 시간 몇 반이 무슨 차시더라"를 확인하려고 매번 앱을 여는 게 번거로워서 만들었습니다.

## 무엇이 보이나

카드 위쪽 칩으로 세 화면을 오갑니다.

| 칩 | 내용 |
|---|---|
| **오늘** | 교시별 수업(학급·종목·차시·주제). 지난 교시는 흐리게, **지금 하는 수업은 초록 테두리**로 강조하고 끝날 때까지 남은 시간을 보여줍니다. 아직 안 한 첫 수업에는 "N분 뒤 시작" |
| **이번주** | 월~금 하루 한 줄. 오늘은 주황 테두리, 휴업일은 흐리게 |
| **진도** | 반별로 오늘까지 나간 차시 수와 막대. 같은 학년에서 가장 빠른 반보다 뒤처지면 `-1` 처럼 빨갛게 |

학사일정 메모(휴업·동아리·고사 등)가 있는 날은 칩과 상관없이 **맨 위에 항상** 표시됩니다.

트레이 아이콘에 마우스를 올리면 오늘 수업이 툴팁으로도 보입니다.

## 값을 어떻게 가져오나

별도 서버나 API 키 없이, **숨은 창으로 수업진도 앱을 띄워 놓고 그 앱이 위젯용으로 내놓는
`window.__widgetData()` 를 부릅니다.** 화면을 긁는 방식이 아니라 앱이 화면을 그릴 때 쓰는 것과
똑같은 계산 결과라서, 앱 화면이 바뀌어도 위젯이 깨지지 않습니다.

구글 로그인은 그 창에서 처음 한 번만 하면 세션이 저장됩니다.
값은 1분마다 자동으로 갱신됩니다.

## 설치

[Releases](../../releases)에서 `JindoWidget-Setup-x.x.x.exe` 를 받아 실행하면 설치되고 바로 실행됩니다.

> Windows 전용입니다. 서명되지 않은 설치 파일이라 처음 실행할 때
> Windows 보안 검사로 잠깐 반응이 없어 보일 수 있습니다 — 강제 종료하지 말고 기다려 주세요.

소스에서 직접 빌드하려면:

```bash
npm install
npm start      # 개발 모드로 실행
npm run dist   # 설치 파일(.exe) 빌드 -> dist/
```

## 처음 실행하면

위젯에 **"수업진도에 로그인해 주세요"** 가 뜹니다.

1. 카드의 **[크롬으로 로그인]** 버튼을 누르세요 — **크롬 탭이 열립니다**
2. 거기서 평소처럼 구글 로그인
3. "위젯에 연결됐습니다" 가 뜨면 그 탭은 닫으셔도 됩니다. 위젯이 알아서 이어받습니다

> 왜 크롬으로 여나: 위젯 안에 띄운 창에서 구글 로그인을 하면 구글이
> *"브라우저 또는 앱이 안전하지 않을 수 있습니다"* 라며 막습니다. 그래서 로그인만 진짜
> 크롬에서 하고, 거기서 받은 토큰을 `127.0.0.1` 로만 위젯에 넘깁니다. 토큰은 컴퓨터
> 바깥으로 나가지 않고, 위젯이 만든 일회용 확인값(nonce)이 맞아야 받아들입니다.

## 위젯이 안 보일 때

위젯은 **작업표시줄에 뜨지 않는** 작은 카드입니다. 처음에는 주 모니터 오른쪽 위에 나타납니다.
못 찾겠으면 작업표시줄 숨겨진 아이콘(`^`)에서 트레이 아이콘을 우클릭 →
**위젯 위치 초기화 (화면 가운데로)** 를 누르세요.

## 트레이 메뉴

| 메뉴 | 설명 |
|---|---|
| 위젯 보이기 | 카드를 숨기거나 다시 표시 (트레이 아이콘 왼쪽 클릭으로도 됩니다) |
| 항상 위로 고정 | 끄면 다른 창에 가려질 수 있습니다 |
| 위젯 투명도 / 위젯 크기 | 100~70% / 소·중·대 |
| 지금 새로고침 | 1분 주기를 기다리지 않고 즉시 갱신 |
| 위젯 위치 초기화 | 주 모니터 한가운데로 데려옵니다 |
| 수업진도 앱 열기 (크롬) | 크롬(없으면 엣지)으로 전체 앱을 엽니다. 기본 브라우저가 무엇이든 상관없습니다 |
| 크롬으로 로그인 | 로그아웃됐거나 세션이 만료됐을 때. 크롬 탭이 열립니다 |
| Windows 시작 시 자동 실행 | 켜두면 부팅할 때 자동으로 뜹니다 |
| 디버그 로그 열기 | 값이 안 뜰 때 확인 (`%APPDATA%/JindoWidget/debug.log`) |
| 업데이트 확인 | 아래 참고 |

카드는 아무 곳이나 **드래그**해서 옮길 수 있고, 위치는 저장됩니다.

## 업데이트

새 버전이 나오면 위젯이 **알아서 백그라운드로 내려받습니다.** 다 받으면 알림이 뜨고,
누르면 위젯이 2~3초 사라졌다가 새 버전으로 다시 뜹니다.
알림을 놓쳤다면 트레이 우클릭 → `🆕 vX.X.X 설치하고 재시작`.

## 만들려면 필요한 것

이 위젯은 수업진도 앱 **v1.25.0 이상**에 있는 `window.__widgetData()` 를 씁니다.
앱이 그보다 낮으면 위젯이 앱을 자동으로 다시 불러옵니다.

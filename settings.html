컴시간알리미

한 번 불러오면 교사·학급 시간표를 함께 저장해 둡니다 — 위에서 볼 것만 골라 두면 다시 불러오지 않아도 바로 바뀝니다. 인터넷이 없어도 계속 보이고, 시간표가 바뀌면 다시 불러오세요.
교사 이름은 컴시간이 김*환처럼 가려서 내려줍니다.
같은 이름으로 가려지는 분이 있을 수 있어 컴시간 앱과 같은 번호를 함께 보여줍니다.

급식 (나이스)

나이스 교육정보 개방포털에서 받아옵니다 — 인증키가 필요 없습니다.
학교를 여럿 담을 수 있습니다 — 검색해서 고르면 아래에 더해집니다. 담은 순서대로 급식 화면에 나오고, ▲▼ 로 순서를 바꿉니다.
(사립처럼 학생은 여중 · 교사 급식은 여고 인 경우에 쓰세요)

전광판

같은 학교 선생님끼리 한 줄씩 주고받는 흐르는 띠 입니다.
비워 두면 런처 목록의 「전광판」 주소를 저절로 씁니다 — 보통은 손댈 것이 없습니다.
컴시간 학교가 같아야 보낼 수 있습니다 — 다른 학교면 보내는 칸이 안 보입니다.
주소를 비우면 그 자리가 아예 안 보입니다.

진도표

개학한 주가 1주차 입니다. 진도표의 주차를 여기서부터 셉니다.
학기마다 한 번만 바꾸시면 됩니다.

바로가기

자주 가는 곳을 담아 두면 위젯 보기의 「바로가기」 탭과 넓게 보기의 「바로가기」 에 타일로 나옵니다. 누르면 위 「바깥 주소를 열 브라우저」 에서 고른 것으로 열립니다.
▲▼ 로 순서를 바꾸고 ✕ 로 뺍니다. 주소 앞에 https:// 를 안 적어도 알아서 붙습니다.

관리자 열쇠 를 넣으면 진호알리미의 「런처보드」 에서 앱을 담고·고치고·빼고, 공유 스위치 로 혜원이지 에 보일지 정할 수 있습니다. 열쇠가 없는 PC 는 공유로 켜 둔 앱만 보이고 고치는 단추가 아예 안 나옵니다.

사용량

위젯에서만 갈립니다 — 넓게 보기는 늘 막대입니다
켠 것만 위젯 제목 줄 아래 띠와 넓게 보기 사이드바에 나옵니다.
AI 는 처음 한 번 «로그인하기» 를 눌러 각각 로그인해야 합니다.
내 PC 는 이 컴퓨터의 CPU·램입니다 — 인터넷도 로그인도 필요 없고 3초마다 다시 잽니다. ChatGPT 는 남은 양을 보여주는 화면이 또렷하지 않아, 못 읽을 수도 있습니다.

날씨 · 미세먼지

목록에 없는 곳은 위도·경도를 넣으세요 — 구글 지도에서 그 자리를 오른쪽 클릭하면 나옵니다.
날씨는 Open-Meteo 에서 받아옵니다. 인증키가 필요 없고, 30분마다 저절로 새로 받습니다.
미세먼지 등급은 환경부 기준(좋음·보통·나쁨·매우 나쁨)입니다.

학사일정 (학교 전체)

학교 «연간 수업일수 계획표» 시트입니다. 학사일정 화면의 3월~2월 날짜·행사·학년별 교시가 여기서 나옵니다.
비우면 학사일정이 통째로 안 나옵니다. 아래 «학년부 일지» 와는 다른 시트입니다.

급식지도 순서표

학교 «급식지도 순서» 시트입니다. 급식 화면에 날마다 지도교사가 붙고, 내 차례는 «10월 2일 · D-34» 처럼 보입니다.
이름은 컴시간에 적힌 이름(김*호)으로 순서표의 온전한 이름(김진호)을 저절로 찾습니다. 잘못 찾으면 위에서 손으로 고르세요.
시간강사·보건교사처럼 순서표에 이름이 없는 분은 급식 화면에 «급식지도 대상이 아닙니다» 라고 나옵니다.

학년부 일지 (우리 학년)

학년부의 «일지» 시트입니다 — 위의 학사일정 시트와 다른 시트입니다.
학사일정 화면의 «학년부» 스위치를 켜면 날짜마다 그 학년의 할 일이 함께 보입니다. 시트의 구분 · 내용 · 세부사항 · 확인 을 읽습니다.
주소는 해마다 바뀝니다 — 새 학년도가 되면 여기서 고쳐 주세요.
학교 «연간 수업일수 계획표» 시트입니다. 내 것이 아니어도 보기 권한만 있으면 됩니다.
다만 «링크가 있는 사람» 으로 공유돼 있어야 읽을 수 있습니다 — 소유자가 «제한됨» 으로 바꾸면 못 읽습니다.
학년이 바뀌어 새 시트가 나오면 여기에 주소를 바꿔 넣으세요.

업무관리 (노션)

노션의 PROJECTS·TASKS 를 위젯에서 보고, 완료·마감일·추가까지 바로 합니다. 진호알리미에만 있는 기능입니다.
준비는 한 번만 하면 됩니다.
① notion.so/my-integrations → «새 통합» 을 만들고 내부 통합 시크릿을 복사합니다
② 노션에서 PROJECTS 와 TASKS 표를 열고, 오른쪽 위 ⋯ → 연결 → 방금 만든 통합 을 추가합니다 (이걸 빠뜨리면 «찾지 못했습니다» 가 납니다)
③ 위 칸에 열쇠를 붙여넣고 저장 → 지금 확인 을 눌러 «연결됐습니다» 가 나오면 끝입니다

열쇠는 이 PC 에만 저장되고 화면에는 다시 보이지 않습니다. 표 주소는 앱에 들어 있어 따로 넣을 것이 없습니다.

학생기록

학생기록 시트는 지금 로그인한 구글 계정에 만들어집니다.
시트와 위젯에서 쓴 내용은 서로 연동되어 어느 쪽에서 고쳐도 함께 바뀝니다.
보통은 여기를 건드릴 일이 없습니다 — 앱에 이미 들어 있습니다.
다른 학교에서 «자기 것»을 쓰고 싶을 때만 아래처럼 만들어 넣으세요.
1. console.cloud.google.com 에서 프로젝트를 하나 만듭니다
2. «API 및 서비스 → 사용자 인증 정보» 에서 OAuth 클라이언트 ID 를 만듭니다. 애플리케이션 유형은 데스크톱 앱 입니다
3. «API 라이브러리» 에서 Google Sheets API 와 Google Drive API 를 켭니다
4. 만들어진 클라이언트 ID 와 비밀값 을 위에 붙여 넣고 저장한 뒤, 위젯의 학생기록 탭에서 «구글 연결하기» 를 누릅니다
쓰는 권한은 «이 앱이 만든 파일» 짜리라 다른 파일은 건드리지 못합니다.
고른 학급만 학생기록에 보입니다. 아무것도 안 고르면 전체가 보입니다.
전교생 명렬표입니다. 내 것이 아니어도 보기 권한만 있으면 됩니다. «통합» 탭을 읽습니다.
학번은 학년1 + 반1 + 번호2 네 자리입니다 (1101 = 1학년 1반 1번).

바깥 주소 열기

수업진도 대시보드 · 구글 로그인 · 주간업무 링크 같은 바깥 주소를 열 때 씁니다.
이 PC 에 깔려 있는 것만 보입니다. «기본 브라우저» 를 고르면 윈도우가 정한 것으로 엽니다.
(구글 로그인은 앱 안 브라우저를 막아서, 진짜 브라우저를 띄워야 합니다)

단축키

다른 프로그램을 쓰다가도 이 키를 누르면 창이 나오고 감춰집니다.
Ctrl · Alt · Shift 중 하나는 꼭 있어야 합니다 — 맨 글자 하나를 잡으면 다른 프로그램에서 그 글자를 못 칩니다.
부르기와 감추기를 같은 키로 두면 번갈아 됩니다.

모양

위젯 보기의 탭 줄과 넓게 보기의 왼쪽 차림표에 함께 걸립니다.
위젯 제목 줄을 두 번 누르면 넓게 보기로 넘어갑니다.
자주 쓰시는 것을 ▲ 로 앞으로 당겨 두세요. 위젯과 넓게 보기가 같은 순서를 씁니다.
대시보드 꾸미기(보여줄 것·차례·크기)는 넓게 보기 대시보드 에서 ✎ 편집하기 를 눌러 하시면 됩니다.

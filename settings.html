컴시간알리미

한 번 불러오면 교사·학급 시간표를 함께 저장해 둡니다 — 위에서 볼 것만 골라 두면 다시 불러오지 않아도 바로 바뀝니다. 인터넷이 없어도 계속 보이고, 시간표가 바뀌면 다시 불러오세요.
교사 이름은 컴시간이 김*환처럼 가려서 내려줍니다.
같은 이름으로 가려지는 분이 있을 수 있어 컴시간 앱과 같은 번호를 함께 보여줍니다.

급식 (나이스)

나이스 교육정보 개방포털에서 받아옵니다 — 인증키가 필요 없습니다.
컴시간과 별개로 고를 수 있습니다. 같은 이름의 학교가 여러 곳이면 교육청·학교종류를 보고 골라주세요.

학사일정

학교 «연간 수업일수 계획표» 시트입니다. 내 것이 아니어도 보기 권한만 있으면 됩니다.
다만 «링크가 있는 사람» 으로 공유돼 있어야 읽을 수 있습니다 — 소유자가 «제한됨» 으로 바꾸면 못 읽습니다.
학년이 바뀌어 새 시트가 나오면 여기에 주소를 바꿔 넣으세요.

학생기록

학생기록 시트는 지금 로그인한 구글 계정에 만들어집니다.
시트와 위젯에서 쓴 내용은 서로 연동되어 어느 쪽에서 고쳐도 함께 바뀝니다.
보통은 여기를 건드릴 일이 없습니다 — 앱에 이미 들어 있습니다.
다른 학교에서 «자기 것»을 쓰고 싶을 때만 아래처럼 만들어 넣으세요.
1. console.cloud.google.com 에서 프로젝트를 하나 만듭니다
2. «API 및 서비스 → 사용자 인증 정보» 에서 OAuth 클라이언트 ID 를 만듭니다. 애플리케이션 유형은 데스크톱 앱 입니다
3. «API 라이브러리» 에서 Google Sheets API 와 Google Drive API 를 켭니다
4. 만들어진 클라이언트 ID 와 비밀값 을 위에 붙여 넣고 저장한 뒤, 위젯의 학생기록 탭에서 «구글 연결하기» 를 누릅니다
쓰는 권한은 «이 앱이 만든 파일» 짜리라 다른 파일은 건드리지 못합니다.
고른 학급만 학생기록에 보입니다. 아무것도 안 고르면 전체가 보입니다.
전교생 명렬표입니다. 내 것이 아니어도 보기 권한만 있으면 됩니다. «통합» 탭을 읽습니다.
학번은 학년1 + 반1 + 번호2 네 자리입니다 (1101 = 1학년 1반 1번).

모양

클로드·제미나이 사용량을 위젯 맨 위에 보여줍니다. 처음 한 번은 위젯의 «로그인하기» 를 눌러 각각 로그인해야 합니다.
